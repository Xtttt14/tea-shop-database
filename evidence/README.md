`sql-validation.txt`为sqlcmd实际执行输出，包括CRUD、充值/券/余额/配送/退款演示、查询结果、15项非法写入拒绝，以及角色授权和越权验证。脚本含明确断言，末尾应为ALL TESTS PASSED；必须同时检查sqlcmd退出码为0，不能只看最后一行。

环境：SQL Server 2025 Express 17.0.1000.7、sqlcmd、ODBC Driver 18。用户名和机器名可能出现在数据库工具输出中，不包含密码。
