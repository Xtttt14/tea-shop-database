# AI使用与人工修改记录

## 已发生的协作

1. 用户提供第一周任务文本，请AI提出候选场景、角色职责、业务流程和数据边界。
2. AI提出校园小卖部、单店奶茶店、文具店和面包店。初始奶茶店候选范围排除了外卖、商城、优惠券及储值。
3. 用户明确修改范围：“以奶茶店作为背景，支持外卖配送、线上商城、优惠券、储值服务，完成第一阶段任务，在当前文件夹下建立github仓库，给出提交内容”。
4. AI读取用户指定的《第一周任务讲解.docx》，识别第一阶段是第1—4周，并询问阶段范围和成员信息。
5. 用户确认：“暂留待填写，第一阶段是1-4周的任务”。
6. AI据此生成需求、关系模式、SQL脚本、阶段报告和测试；实际连接本机SQL Server验证并修正发现的问题。
